# Apple Music 原词同步 · Halo PixelBar

为 Windows 原生 Apple Music 和花再 Halo PixelBar A160 编写的本地托盘工具。音乐仍由 Apple Music 播放；工具从你的 Apple Music 订阅获取苹果原始歌词和时间轴，通过 USB 更新音响屏幕。Apple Music 和本工具均可最小化。

## 使用

1. 双击项目目录的 `启动歌词同步.cmd`，或运行 `dist\HaloLyrics\HaloLyrics.exe`。发布版本自带 .NET 运行时，无需安装 SDK。
2. 第一次使用时，在程序打开的 Apple 官方页面完成登录。登录成功会返回主窗口。
3. 从系统托盘退出 **EDIFIER TempoHub**，保留其安装和 Windows 音频驱动。两个控制程序同时运行会争抢屏幕。
4. 在原生 Apple Music 中播放歌曲，点击本工具的 **开始同步**。曲目存在多个版本时，选择与实际录音对应的版本；程序会记住选择。
5. 歌词偏晚时增大 **歌词提前（毫秒）**，偏早时减小；正数提前、负数延后，按 50 毫秒调整。设置自动保存。本机已校准过的设置会继续保留。
6. **歌词进出动画** 可选择截图中的五组设备原生组合，或“无动画（静态）”。设备将进出效果成对提供。**长间奏显示音乐律动** 默认开启，间奏至少 5 秒时切换到音响内置律动画面；可调整为 3–30 秒，下一句开始时自动恢复歌词，暂停时停止律动画面。

关闭主窗口会进入托盘，音乐歌词继续同步。点击 **暂停同步** 或 **退出并恢复屏幕** 会恢复接管前的屏幕。也可在托盘图标上双击打开窗口、右键退出。默认手动启动，不设置开机自启。

## 显示行为

- 只跟随 Windows 原生 Apple Music，不切换到其他播放器或其他歌词源。
- 繁简体、大小写和文字内容保持原样。长句按设备的 16 字符／48 字节容量分段，避免切坏 Unicode 字符；屏幕显示能力受音响字库限制。
- 前奏、间奏时清空上一句；已知歌词时间轴中的长空档可显示内置律动。无同步歌词时显示明确状态，不用其他平台歌词替代。获取失败后可点击 **重新匹配** 重试。
- 暂停和拖动进度后，根据播放器最新时间重新定位。曲目版本、设备和播放进度共同影响同步效果，可通过补偿微调。
- USB 断开后定期重试；恢复记录保留最初的屏幕状态。断开期间退出时，恢复记录保留到下次连接该设备并同步、暂停时处理。
- Apple 授权过期时点击 **Apple 登录**。歌词接口未公开，苹果更新后可能需要适配。

## 本机数据

所有运行数据位于 `%LOCALAPPDATA%\HaloLyrics`，不会写入源码或发布包：

- `apple-session.dat`：Windows 当前用户 DPAPI 加密的 Apple 会话；不能直接复制到另一用户使用。
- `WebProfile`：此工具专用的网页登录资料。
- `settings.json`：同步补偿、动画选项、间奏阈值和已确认的曲目对应关系。
- `Lyrics`：从 Apple 获取的 TTML 歌词缓存。
- `screen-restore.json`：待恢复的屏幕快照；恢复确认后移除。
- `status.json`、`activity.log`：当前状态与有限长度的运行日志，不记录令牌和密码。

本机系统代理对 Apple 登录域名连接失败，工具因此单独使用直连；不修改系统代理。工具没有本地网络监听端口，也不要求管理员权限。

## 编译与检查

需要 .NET 10 SDK。Windows 终端使用 PowerShell 7：

```powershell
& 'C:\Program Files\PowerShell\7\pwsh.exe' -NoProfile -File '.\tools\Build.ps1'
```

脚本优先使用项目的 `.tools\dotnet`，否则使用系统 SDK。运行 `tools\Build.ps1 -TestOnly` 只执行自动检查。源码位于 `src\HaloLyrics`，自动检查位于 `tests\HaloLyrics.Tests`。

这是独立的本地辅助工具，不隶属于 Apple 或漫步者。
